# Examples

This page is the `examples/` folder. Its own `README.md` is this text, and the
pages listed below are the folder's files and subfolders, which Confluence
lists here on its own.

- [Rendering examples](rendering-examples.md): every kind of Markdown, as it
  looks once published.
- [Page nesting](page-nesting/README.md): how folders and files become a tree
  of pages.

The rendering examples page used to sit one level up. Moving its file here
kept the same page, with the same ID and URL, because its title didn't change.
